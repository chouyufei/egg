# 蛋速达 · 微信小程序

养殖场（卖方）和采购商（买方）两端的原生微信小程序，对接 `chouyufei/rest` 仓库下的 `egg-platform/` 后端。

> 管理员端在 PRD 中明确是 Web 后台，因此小程序只覆盖养殖场和采购商。管理员登录小程序后会引导到 Web 后台。

## 在你电脑上跑起来

### 1. 启动后端

```bash
cd rest/egg-platform
npm install
npm start              # 默认监听 :3000
```

看到 `蛋速达 API running on http://localhost:3000` 即成功。

### 2. 用「微信开发者工具」打开小程序

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → **导入项目**
3. **项目目录**：选 `egg/`（不是 `egg/miniprogram`，根目录有 `project.config.json`）
4. **AppID**：填测试号 / 任意已申请的小程序 AppID（仓库里默认是 `touristappid`，工具会提示）
5. 点导入

### 3. 关键设置：允许访问 localhost

开发者工具默认不允许访问非 HTTPS / 非合法域名的接口，必须放开：

> **详情 → 本地设置 → 勾选**「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」

放开后小程序就能调用 `http://localhost:3000/api/*`。

### 4. 登录使用

打开小程序，登录页演示账号（**验证码统一 `123456`**）：

| 想看什么 | 选身份 | 手机号 |
|---|---|---|
| 采购商首页 / 出价 / 中标 / 收货 | 采购商 | `13900000001` |
| 养殖场工作台 / 发布 / 沟通群 | 养殖场 | `13800000001` |
| 资质待审核（管理员要在 Web 后台通过） | 养殖场 | `13800000003` |

## 页面结构（已实现）

```
小程序 4 个 tab：
├─ 首页 (index)
│   ├─ 采购商：Hero/搜索/快捷分类/即将结束/新发布
│   └─ 养殖场：工作台/资质提示/保证金提示/统计/我的资源
├─ 竞拍 (auction)
│   ├─ 采购商：浏览全部（搜索+筛选+排序）/ 我的竞拍（进行中/已中标/未中标）
│   └─ 养殖场：我的资源（全部/竞拍中/已成交/已流拍）
├─ 订单 (orders)：双方共用，按角色自动过滤
└─ 我的 (me)：角色感知的资料与入口

子页面：
├─ 资源详情 (resource-detail)：图轮播 / 倒计时 / 参数 / 出价记录 / 出价栏 / 自动出价
├─ 订单详情 (order-detail)：信息 / 沟通群（建群+IM）/ 确认收货 / 纠纷
├─ 发布资源 (publish)：完整发布表单
├─ 资质认证 (qualify)：养殖场提交营业执照
├─ 保证金 (deposit)：缴纳 / 历史记录
└─ 消息中心 (messages)：所有通知（出价/中标/延时/纠纷...）
```

## 切换 API 地址

如果后端不在 `localhost:3000`，改 `miniprogram/app.js` 第 3 行：

```js
apiBase: 'http://localhost:3000/api',
//        ↑ 改成你的后端地址，如 'https://your-domain.com/api'
```

## 真机预览注意事项

开发者工具里点「预览」生成二维码扫码后会发现请求失败 — 这是因为：

1. 真机不在你电脑的局域网内，看不到 `localhost`
2. 微信小程序在真机上**只允许 HTTPS** 接口，且域名必须在小程序后台 **服务器域名** 白名单里

正式上线前需要：

1. 把后端部署到有 HTTPS 的服务器
2. 到 [小程序后台](https://mp.weixin.qq.com) → 开发 → 开发管理 → 服务器域名 → 把后端域名加到 `request 合法域名`
3. 修改 `app.js` 中的 `apiBase` 为新域名

## 业务规则

所有 PRD 业务规则都在后端 (`rest/egg-platform`) 实现，前端是消费者：

- 出价 ≥ 当前价 + 2 元
- 最后 5 分钟出价自动延长 5 分钟，最多 3 次
- 双向保证金（养殖场 1000 / 采购商 200），冻结-解冻链路
- 中标 7 天未拉群 → 扣保证金
- 沟通完成 7 天未确认 → 系统自动确认释放保证金
