> 也支持采购商发布求购、养殖场应标。
> 公司：湖北省乘子农业科技有限公司 · 客服：186-7554-5968

## 1. 总览

| 端 | 仓库 / 目录 | 技术栈 |
|---|---|---|
| 微信小程序（用户端） | `chouyufei/egg` → `miniprogram/` | 原生小程序（WXML/WXSS/JS） |
| 管理后台（Web） | `chouyufei/egg` → `src/` | Vue 3 + vue-router(hash) + vant + axios |

- **开发分支（两仓库同名）**：`claude/egg-trading-platform-uYSOL`
- **提交规范**：改动 → `commit`（中文说明）→ `git push -u origin <branch>`；不主动建 PR。
- **小程序生效**：改完必须在微信开发者工具**重新编译/上传**，仅推仓库不会更新到设备。

### 角色模型
- `farm` 养殖场（卖方）｜ `buyer` 采购商（买方）｜ `admin` 管理员。
- 同一用户可在小程序首页切「买/卖」，前端调 `/auth/switch-role` 改 DB `role`。
- **资质认证与角色解耦**：切模式不改 `license_status`（历史上曾耦合，已修复）。

## 2. 后端架构（egg-platform）

### 2.1 启动与分层
- `src/server.js` 挂载各路由到 `/api/*`，静态目录 `/uploads`。
- `src/middleware/auth.js`：`authRequired`（校验 Bearer JWT，注入 `req.user`）、
  `roleRequired(...roles)`、`sign(user)`、`JWT_SECRET`。
- `src/routes/*`：业务路由。`src/services/*`：领域逻辑。`src/db.js`：schema + 迁移。

### 2.2 数据库（better-sqlite3，同步 API）
表：`users` `deposits` `resources` `bids` `auto_bids` `orders` `messages`
`disputes` `chat_messages` `pay_orders` `app_settings` `balance_transactions`
`withdrawals` `reports`。

迁移方式：`addColumnIfMissing(table, col, ddl)` 增量加列；复杂结构变更用**一次性迁移 IIFE**，
以 `app_settings` 里的标记位防止重复执行（如 `deposits_new` / `withdrawals_new` 重建表）。

**核心表关键字段**
- `users`：`role` `license_status`(none/pending/approved/rejected) `license_pending`(JSON快照)
  `name/contact_name/address/region/business_license` `farm_size_int`(只) `daily_output`
  `main_products` `license_photos/farm_photos/quarantine_photos`(JSON) `balance/locked_balance`(分)
  `wechat_openid` `phone` `lat/lng` `banned`。
- `resources`：`kind`(supply/demand) `farm_id`(发布者) `title/region/province/egg_color/chicken_breed`
  `weight_spec` `weight_specs`(JSON 各斤值箱数/价格) `pack_size/yolk_color/yolk_shade/truck_type`
  `quantity` `start_price/current_price/min_increment` `current_bidder_id` `status`
  (auctioning/sold/failed/cancelled) `start_at/end_at` `allow_provinces`(JSON,求购限定省份)
  `lat/lng` `deleted_at`(软删) `defect_rate/defect_note` `photos`(JSON) `unit_label/unit_size`。
- `bids`：`resource_id` `bidder_id` `price` `is_auto` `max_price` `created_at`。
- `orders`：`resource_id` `farm_id` `buyer_id` `final_price` `order_no`(16位) `status`。
- `withdrawals`：提现单，`method`(wechat/bank) `status`(pending/approved/paid/failed/transferring/…)。
- `balance_transactions`：钱包流水（分位整数）。

## 3. 数据 / 金额约定（务必遵守）

- **金额一律分位整数**运算（`services/balance.js`：`getBalance/txDebit/txPureDebit`），
  杜绝 IEEE-754 误差导致"够却提示不够"。`debit()` 允许透支（记负，待对账）。
- **服务保障金**（旧称保证金，统一改此名）：后台可配 `deposit_amount`（默认 500 元），
  **只冻结/扣卖方**；发布货源 / 发起求购 / 参与报价均冻结同额。
  订单完成时扣 `service_fee_amount`（默认 500）作平台服务费，余下解冻。
- **养殖规模单位＝万只**：表单按「万只」录入，DB 存 `farm_size_int`（只）＝ 万只 × 10000；
  所有展示处（资质表单/详情、货源详情、卖家信用、后台）统一显示「万只」。
- **weight_specs**：`[{weight, boxes, price}]`，每个净重斤值一行的箱数与价格。

## 4. 主要 API（`/api` 前缀）

> `A`=需登录(authRequired)，`P`=公开（游客可访问），`Adm`=管理员。

### 4.1 auth（`/api/auth`）
`POST /admin-login` `POST /change-password`(A) `GET /login-modes` `GET /notice-templates`
`GET /app-config`（拉 review_mode 等）`POST /send-otp` `POST /login` `POST /wechat-login`
`POST /switch-role`(A，仅改 role) `POST /bind-phone`(A) `GET /me`(A) `POST /location`(A)
`PATCH /me`(A，改昵称等) `POST /qualify`(A，任何登录用户可提交资质)。

### 4.2 resources（`/api/resources`）
`GET /`(P，列表；支持 kind/status/region/province/color/keyword/near_lat/near_lng)
`GET /mine`(A) `GET /last-published`(A) `GET /seller/:userId`(P，卖家信用)
`GET /:id`(P，详情) `POST /`(A，发布) `POST /:id/relist`(A，重新上架，保留 weight_specs/allow_provinces)
`PATCH /:id`(A) `POST /:id/cancel|delete|end-now`(A)。

### 4.3 bids（`/api/bids`）
`POST /`(A，报价/让价，含 allow_provinces 地区拦截 + 资质校验) `POST /auto`(A，自动出价)
`DELETE /auto/:resource_id`(A) `GET /mine`(A)。

### 4.4 orders / deposits / messages / wallet / pay / reports
- orders：`GET /` `GET /:id` `POST /:id/create-group|chat|confirm|dispute`（confirm 先结算保障金再解冻）。
- deposits：`GET /` `GET /status` `POST /lock` `POST /refund/:id`。
- messages：`GET /` `GET /unread-count` `POST /read`。
- wallet：`GET /withdraw-rules` `GET /balance` `GET /transactions` `POST /withdrawals`
  `GET /withdrawals/mine` `POST /withdrawals/:id/confirm-received|cancel`。
- pay：`GET /mode` `POST /create-order` `POST /recharge` `POST /notify`(微信回调) `GET /check/:out_trade_no`。
- reports：`POST /` `GET /mine` `GET /categories`。

### 4.5 admin（`/api/admin`，均需管理员）
统计 `GET /stats`；用户 `GET /users` `POST /users/:id/approve|reject|ban`；
资源 `GET /resources`（支持 kind/status 过滤，返回发布人手机号 + 报价数）
`POST /resources/:id/takedown` `PATCH /resources/:id` `DELETE /resources/:id`（软删）；
订单 `GET /orders`；保证金 `GET /deposits` `POST /deposits/:id/deduct` `POST /reconcile-deposits`；
纠纷 `GET /disputes` `POST /disputes/:id/resolve`；
配置 `GET|PUT /notice-settings` `GET|PUT /deposit-settings` `GET|PUT /service-qr` `GET|PUT /review-mode`；
提现 `GET /withdrawals` `POST /withdrawals/:id/approve|reject|mark-failed|mark-paid`；
管理员账号 `GET/POST /admins` `POST /admins/:id/reset-password` `DELETE /admins/:id`。

## 5. 关键业务流程

### 5.1 竞价撮合
1. 卖方发布货源（或买方发布求购），冻结服务保障金，设订单有效期 30/60/90 分钟。
2. 对方在线报价：货源＝加价、价高者优先；求购＝让价、价低者优先（`services/auction.js` placeBidTx）。
   每次报价通知发布方（`notifyNewBidToPublisher`）、通知被反超者（`notifyOutbid`）。
3. 有效期到，系统自动按当前最优价成交，生成订单（`order_no` 16 位）。
4. 成交下发客服企业微信二维码，双方扫码进群沟通发货。
5. 买方确认收货 → 结算：扣卖方服务费、解冻余额（7 天无操作且无纠纷自动确认）。

### 5.2 资质认证（养殖场，任何登录用户可提交）
- 新提交/驳回后重交：直接写正式字段，状态 `pending`。
- **已通过用户重新提交**：新资料存 `license_pending`(JSON 快照)，正式字段不动，状态 `pending`；
  审核通过（`/admin/users/:id/approve`）才用快照覆盖；驳回则丢快照、状态回 `approved`。
- 后台「资质审核」按 `license_status` 筛选、**不限角色**，并按快照展示"本次实际提交"。

### 5.3 钱包 / 提现 / 充值
- 充值走微信支付（`routes/pay.js`，公钥模式）。
- 提现：微信零钱单笔 ≤200 元实时到账（商家转账 transfer-bills，scene 1011）；
  银行卡单笔 ≤5000 元、2 小时内到账（管理员人工打款）。转账失败→退款 + 状态 failed。
- **微信审核红线**：不得出现"提现门槛"，须"实时提现 / 2 小时内到账"话术。

### 5.4 通知
站内信 + 微信订阅消息（单模板多场景 RESULT_TEXTS）+ 短信 + 企业微信机器人。
**短信按模板 ID 区分类型（模板不支持参数）**：
订单提醒 `2657517` / 报价提醒 `2673307` / 货源提醒 `2673308`；平台方 `2657523`
（env `SMS_NOTICE_TPL_ORDER/QUOTE/SUPPLY` 可覆盖）。
距离推送：发布货源/求购给 `push_radius_km`（默认 500km）内用户推订阅 + 短信（`services/geo.js` distanceKm）。

## 6. 小程序端（miniprogram）

### 6.1 页面
`index`(首页) `login` `me`(我的) `orders`(订单) `resource-detail`(货源/求购详情)
`order-detail` `publish`(发布) `qualify`(资质) `wallet`/`withdraw`/`recharge`
`messages` `seller-profile`(卖家信用) `settings`(界面设置) `report` `about/agreement/privacy` 等。
启动页＝`index`（支持游客）。

### 6.2 关键 utils
- `api.js`：请求封装。**删除方法是 `api.del`**（后台 `src/api` 才是 `api.delete`）。
  401 时清登录态并回首页（游客继续浏览）。
- `auth.js`：`isLoggedIn()` / `requireLogin(action)`（游客触发受限操作弹框引导登录）。
- `prefs.js`：字体大小(normal/large/xlarge) + 主题(day/night)，见 §6.4。
- `share.js`：`defaultShare()` 分享封面 `/images/share-logo.png`。
- `location/subscribe/deposit/format/upload`。

### 6.3 游客模式
未登录可浏览 首页/订单/我的/详情/卖家信用；受限操作（发布/报价/下单/钱包/消息）弹框引导登录。
详情页与卖家信用后端为公开接口。

### 6.4 界面设置（字体 / 主题）
- `utils/prefs.js` 持久化偏好，`app.js` 启动读入 globalData。
- 通过 `<page-meta page-style>` 注入 CSS 变量：`--fs-scale`(字体缩放 1/1.15/1.3)、
  `--bg/--fg/--card/--muted`(主题色)。`app.wxss` 用 `var()`+`calc()` 全局响应。
- 已接入 首页/订单/我的/设置。**限制**：小程序 rpx 无全局倍率，写死 rpx 的字号不随缩放；
  组件（如 `egg-card`）样式隔离，不随全局主题/字体变化。

## 10. 术语与坑（Checklist）

- 术语统一：**出价/报价/加价（货源）/让价（求购）**；**不用**竞拍/竞价/还价。保证金＝**服务保障金**。
- 养殖规模＝**万只**（DB 存只）。
- `api.del`（小程序）vs `api.delete`（后台）。
- `wx.requestSubscribeMessage` **必须用户手势触发**，放在报价/发布等动作点。
- 余额比较用**分位整数**。
- relist 的 UPDATE 必须带 `weight_specs`、`allow_provinces`（否则被清空——历史坑）。
- 小程序改完**重新编译/上传**才生效。
- 沙箱内 libreoffice docx→pdf 不可用，PDF 用 Chromium(`/opt/pw-browsers`) HTML→PDF。
