# 凤伯乐 · 鸡蛋竞拍撮合平台前端

> **一句话定位**：让你的蛋，自己定价。
> 养殖场（卖方）自主发布资源 → 采购商（买方）公开竞拍 → 价高者得 → 双向保证金保障交易。

基于 Vue 3 + Vite + Vant 4 构建，覆盖三端：

| 端 | 路径 | 适配 | 说明 |
|----|------|------|------|
| 养殖场 | `/#/farm` | 手机（小程序风格） | 资质认证、缴保证金、发布资源、查看出价、订单沟通 |
| 采购商 | `/#/buyer` | 手机（小程序风格） | 浏览推荐/搜索筛选、出价/自动出价、确认收货、纠纷 |
| 管理后台 | `/#/admin` | 桌面 Web | 看板、用户/资源/保证金/纠纷管理 |

## 快速开始

需要先启动后端（见 `chouyufei/rest` 仓库的 `egg-platform/` 目录）。

```bash
npm install
npm run dev       # 默认 :5173，自动代理 /api → http://localhost:3000
```

打开浏览器访问 `http://localhost:5173/` 后选择身份登录。

## 关键交互

- **首页竞拍卡片**：封面图 + 当前价 + 倒计时 + 起拍价 + 出价数
- **资源详情**：图轮播 → 当前价/倒计时 → 参数明细 → 出价记录（实时刷新）→ 出价/自动出价
- **自动出价**：设置最高心理价，被反超时系统自动加 `min_increment` 出价
- **延时机制**：最后 5 分钟有出价，倒计时自动 +5 分钟，最多 3 次
- **订单详情**：拉群、IM 消息、确认收货、发起纠纷
- **管理后台**：看板（GMV / 成交率 / 溢价率）、资质审核、资源下架、保证金扣款、纠纷仲裁

## 技术栈

- Vue 3 (Composition API) + Pinia + Vue Router (hash 模式)
- Vant 4 — 移动端 UI，与小程序原生组件视觉一致
- axios — `/api` 代理至后端
- dayjs — 时间格式化
- 实时性：每个详情/订单页 5 秒轮询（生产可替换为 WebSocket / 长轮询）
