# 凤伯乐 · 鸡蛋询价撮合平台 — 小程序使用文档

> 让你的蛋，自己定价。
> 养殖场（卖方）发布货源、采购商（买方）公开报价，价高者得；也支持采购商发布求购、养殖场应标，价低者优先。平台仅作中立的信息撮合与服务保障方。

适用版本：v1.0.0

---

## 一、产品简介

凤伯乐是一个鸡蛋供需撮合小程序，核心玩法：

- **发布货源**：养殖场把要卖的鸡蛋挂出来，采购商在线公开报价，出价越高越靠前，到期价高者成交。
- **发布求购**：采购商把想买的需求挂出来，养殖场在线应标报价，价低者优先。
- **服务保障金**：发布/参与时从钱包冻结一笔保障金，保证交易诚信；订单完成后由卖方扣一笔服务费，其余解冻。
- **就近撮合**：按你设置的位置优先推荐附近的货源/求购，并推送附近的新发布提醒。
- **客服协助**：成交后由平台客服协助对接发货、对货、回款。

> 平台不直接参与买卖本身，只提供信息撮合、报价对接、订单管理与客服协助。

## 二、名词解释

| 名词 | 含义 |
|---|---|
| 货源 | 养殖场发布的"我有蛋要卖" |
| 求购 | 采购商发布的"我要买蛋" |
| 出价 / 报价 | 对一条货源/求购给出自己愿意的价格 |
| 加价 | 货源场景下买方往上抬价（价高者得） |
| 让价 | 求购场景下卖方往下让价（价低者优先） |
| 服务保障金 | 发布/参与时冻结的诚信保证金，可随订单结算解冻或退回 |
| 服务费 | 订单成交后平台从卖方保障金里扣除的费用 |
| 订单有效期 | 一条发布的报价持续时间，到期自动按当前最优价成交 |

## 四、资质认证（养殖场必看）

**发布货源前，养殖场必须先完成资质认证并通过审核。** 采购商发布求购、参与货源出价不需要资质；但应标（参与求购）需要养殖场资质。

### 4.1 提交资质
进入「我的 → 资质认证」，填写：

- 鸡场名称、联系人、联系电话、所在省份
- **详细地址**：可点右侧「📍 地图」在地图上选点自动填入，也可手填
- 养殖规模、日产量、主营蛋品、营业执照号
- 上传营业执照照片、鸡场实景照（必传），检疫合格证等（可选）

填完点「提交审核」，状态变为「审核中」，平台会尽快核实。

### 4.2 审核结果
- **通过**：状态变「已通过」，即可发布货源、参与求购。
- **未通过**：按提示补充资料后重新提交。

### 4.3 通过后还能修改
已通过的用户在资质页可点「✏️ 修改资质并重新提交审核」：

- 修改提交后会重新进入审核；
- **审核通过前仍按你现有的资质生效**，不影响正常使用；
- 审核通过后新资料才覆盖旧的，被驳回则保留原资质。

### 4.4 查看已提交资质
通过 / 审核中状态下，可点「📜 查看已提交资质详情」展开查看你提交过的全部信息和照片。

> 若照片显示不出来，多为网络/域名问题，可联系平台客服。

## 五、钱包与服务保障金

进入「我的 → 我的钱包」。

### 5.1 余额构成
- **账户余额**：你的钱包总额。
- **可提现**：可以申请提现的部分。
- **冻结**：发布/参与时锁定的保障金，暂不可提现，但不影响浏览、咨询、查看订单。

### 5.2 充值
点「💰 充值」，按提示用微信支付充值，到账后计入账户余额。

### 5.3 保障金规则
- 发布货源 / 发布求购 / 参与报价时，系统自动从「可用余额」冻结一笔**服务保障金**（默认 500 元，以发布时显示为准）。
- **同一条货源/求购内多次出价，只冻结一次**，不会重复扣。
- 余额不足时会提示去充值，充值后自动回到原页面继续操作。

### 5.4 成交后如何结算
- 订单完成（采购方确认收货）后，平台**仅从卖方**的保障金里扣一笔服务费（默认 500 元）。
- 买方冻结的保障金在成交后**全额解冻**回可用余额。
- 未成交 / 取消的发布，所冻保障金全额解冻，不收任何费用。

### 5.5 余额流水
钱包页「余额流水」可查每一笔变动，用颜色区分：
- 🟢 绿色：实际到账　🔴 红色：实际出账
- 🔒 冻结（不扣款）　🔓 解冻

## 六、发布货源（养殖场）

首页顶部切到「卖」，点发布入口进入发布页（需资质已通过）。

### 6.1 基础信息
- 标题、省份
- **定位**：可在地图选点，作为附近推荐依据
- 蛋品类目（粉壳 / 红壳 / 土鸡 / 乌鸡 / 白壳）
- 鸡种（按蛋色自动给出常见品种下拉）

### 6.2 规格与品质
- 蛋黄颜色（红心 / 黄心 / 双色）+ 蛋黄色号
- 鲜度（X 天内）
- 次品率（默认 0.2%，= 裂纹蛋+脏蛋+破蛋占比的承诺上限）
- 规格（360 / 480 枚/箱 或自填）
- **单箱净重区间**：如 20—22 斤/箱，区间跨度最多为 2（即最多 3 个整数斤值）
- 车型：4.2 / 6.8 / 9.6 / 13.5 米车

### 6.3 各规格箱数 / 价格（重点）
填好单箱净重区间后，系统按每个整数斤值自动列出几行，例如 20—22 会出现「20 斤箱 / 21 斤箱 / 22 斤箱」三行，每行分别填：

- **箱数**：该规格有多少箱
- **起报价**：该规格每箱起报价（元/箱）

注意：
- 所有规格的**总箱数不能超过所选车型容量 + 50 箱**（含少量装载冗余），超了会有提示。
- 列表卡片上展示的价格以**最小净重对应的起报价**为准，其它规格在详情页展示。

### 6.4 成交规则
- 加价幅度：买方每次至少加多少（默认 1 元/箱）
- **订单有效期**：30 分钟 / 60 分钟 / 90 分钟
- 到期后系统自动选当前**最优报价**成交；到期无人报价则未成交。

### 6.5 图片
- 最多 9 张，第 1 张为封面。
- **长按某张图片**可调整顺序（设为封面 / 前移 / 后移）。

### 6.6 沿用上次
发布页右上角「📋 沿用上次」可一键填入你上一次发布的全部内容，改改即可再发，省去重复填写。

## 七、发布求购（采购商）

首页切到「买」相关入口发布求购，字段与货源类似，差异点：

- 价格为「心理价上限」，对应**让价**玩法（养殖场应标，价低者优先）。
- 可设置「**允许参与地区**」：
  - 多选省份，默认「不限」（全部可参与）；
  - 选定后，**只有所在地区匹配的养殖场**能对这条求购出价。
- 同样支持蛋黄颜色、鲜度、单箱净重区间、车型、各规格箱数/价格等。

## 八、浏览与出价

### 8.1 首页浏览
- 顶部「买 / 卖」切换查看货源或求购。
- 顶部定位条显示当前位置，点「更换」可重新选位置，系统优先推荐你附近 500km 内的发布。
- 类目 / 区域筛选可缩小范围。

### 8.2 资源详情
点任意卡片进入详情，可看：当前价、倒计时、参数明细（数量、净重、规格、蛋黄颜色、鲜度、各规格箱数/价格等）、报价记录、发布方信用（点「查看信用 / 主页」进入对方主页）。

### 8.3 出价
1. 点底部「💰 我要加价 / 我要让价」。
2. 在弹窗里用 - / + 或滑块选择你的价格。
3. 点「确定」后会再弹一次确认；确认后即提交。
4. 出价成功会有「✅ 报价成功」提示，可在「我的参与」查看进展。

注意：
- 首次出价会自动冻结一笔服务保障金（同一条只冻一次）。
- 你出的价会作为最小净重价，其它规格价格按差额同步联动。
- 求购出价需养殖场资质已通过，且所在地区在发布方允许范围内。

### 8.4 分享裂变
详情页有「📣 邀请好友围观」卡片，点「立即分享」转发给好友/群；右上角「…」也可转发或分享到朋友圈。关注的人越多，价格冲刺越快、越早锁货。

> 通过分享链接进入的未登录访客也能浏览详情，底部会提示登录后参与。

## 九、订单与履约

### 9.1 成交生成订单
报价到期或发布方手动确认后生成订单。买卖双方都会收到通知，并下发**平台客服企业微信二维码**——交易履约或沟通中如有疑问，可扫码加客服咨询、由客服协助对接。

### 9.2 订单列表
底部「订单」进入。一个账号可能既卖又买，列表用**大色块标识**区分：
- 🟢「卖单 · 我的货源被采购」
- 🔵「买单 · 我参与的采购」

不论首页切到买还是卖，订单列表都能看到你全部的买/卖订单。

### 9.3 订单详情
展示订单编号、参数明细（蛋品/鸡种/蛋黄颜色/鲜度/次品率/规格/单箱净重/车型，及各规格箱数与**成交价**）、对方联系方式、距离与路线等。

- 点「📍 距离」可查看到对方的路线地图，「我的位置」可临时更换。
- 订单编号可点击复制，方便向客服反馈。

### 9.4 确认收货
买方（参与货源出价方 / 发布求购方）在沟通完成后点「确认收货」：

- 确认后保障金按规则结算（卖方扣服务费、买方全额解冻）；
- **7 天未操作系统自动确认**。

## 十、提现

进入「我的 → 我的钱包 → 申请提现」。

### 10.1 额度规则
| 方式 | 单笔上限 | 每日次数 | 每日累计 |
|---|---|---|---|
| 微信零钱 | 200 元 | 10 次 | 2000 元 |
| 银行卡 | 5000 元 | 3 次 | 5000 元 |

- 最低单笔 0.01 元；两种方式分别计算次数与累计，互不相通。
- 受理时段 7×24 小时，提交后实时处理，无需人工排队审核。

### 10.2 到账时效
- **微信零钱**：提交后立即发起，按提示在微信「确认收款」弹窗里确认即实时到账（转入你登录所用的微信号）。
- **银行卡**：填写持卡人/卡号/开户行，平台人工打款，2 小时内到账。

### 10.3 提现记录
钱包页「提现记录」可查状态：
- 待您在微信确认收款 / 平台已打款 / 已取消 / 打款失败（金额已退回）等。
- 未到账前可在记录里取消。
- 若提现失败，金额会自动退回钱包，可稍后再试。

## 十一、消息提醒

### 11.1 开启提醒
首次进入首页会弹「开启消息提醒」，点「开启」并授权后，以下情况会第一时间提醒你：
- 附近有新货源 / 新求购
- 你发布的货源被报价
- 你的报价被反超

### 11.2 提醒渠道
站内消息（消息中心）+ 微信订阅消息 +（如平台开启）短信。

### 11.3 附近推送
平台按你在首页设置的位置，与新发布的货源/求购位置计算距离，在设定范围内（默认 500km）才会推送给你。**改了首页定位，匹配范围也随之更新。**「我的」页顶部会显示你当前的位置。

## 十四、常见问题（FAQ）

**Q：明明有余额却提示余额不足？**
A：已修复因金额小数精度导致的误判。如仍遇到，请退出重进或联系客服。

**Q：为什么我不能对某条求购出价？**
A：求购出价需满足两点：① 养殖场资质已通过；② 你所在地区在发布方「允许参与地区」范围内。

**Q：同一条货源出价几次，要交几次保障金？**
A：只交一次。同一条发布内多次出价不会重复冻结。

**Q：重新上架会不会产生重复的货源？**
A：不会。重新上架是复用原来那条货源（更新内容、重置状态），发布成功后回到首页。

**Q：发布货源时提示不能发布？**
A：发布货源需先完成养殖场资质认证并通过审核。

**Q：分享出去单位显示对不对？**
A：分享文案与详情统一以「箱」为单位。

**Q：收不到消息提醒？**
A：请确认进入小程序时点了「开启」并在微信里授权了订阅消息；订阅消息为一次性授权，可能需要再次开启。短信是否发送取决于平台配置。
