# 凤伯乐 品牌资产

## 文件清单

| 文件 | 用途 | 推荐尺寸 |
|---|---|---|
| `logo-app.svg` | 小程序图标 / favicon / 头像 | 512×512（导出为 PNG） |
| `logo-horizontal.svg` | Web 后台页眉、名片、邮件签名 | 900×280 |
| `logo-vertical.svg` | 启动屏、海报、易拉宝 | 480×640 |
| `logo-mono.svg` | 印章、水印、传真、单色印刷 | 任意 |

## 配色

- 主金：`#f6b821`
- 浅金：`#ffd84d`
- 深金：`#f08a00` / `#e0a40d` / `#b78300`
- 文字深：`#1d1d1f`
- 文字辅：`#8a6b15`

## 设计概念

- **金蛋**：平台主体（鸡蛋撮合），白色蛋身 + 金色光泽
- **凤羽**：自蛋顶升起的火苗状曲线，呼应「凤」，也象征拍卖价格上扬
- **凤 字**：作为蛋上的暗金印记，强化品牌识别
- 整体语义："凤伯乐"——像古代伯乐识千里马一样，为养殖场和采购商识别好蛋、撮合好价

## 导出 PNG

```bash
# 需要安装 rsvg-convert 或 inkscape
rsvg-convert -w 512 -h 512 logo-app.svg > logo-app-512.png
rsvg-convert -w 1024 -h 1024 logo-app.svg > logo-app-1024.png
rsvg-convert -w 1800 -h 560 logo-horizontal.svg > logo-horizontal-1800.png
```

或者直接把 SVG 拖进 Figma / Sketch / 浏览器右键另存为。
